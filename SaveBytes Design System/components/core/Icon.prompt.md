Lucide icon at the brand stroke (1.75), loaded from CDN and inheriting currentColor; use for every glyph in UI.

```jsx
<Icon name="arrow-right" size={16} />
<Icon name="circle-alert" size={20} color="var(--color-danger)" label="Error" />
```

- Sizes: 16 inline with text, 20 in buttons/nav.
- Never use emoji or medical clichés (crosses, stethoscopes, heartbeat lines, DNA, pills) as decoration.
